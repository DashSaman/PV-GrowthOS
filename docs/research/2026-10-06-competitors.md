## تصمیم‌های عملی برای PV

۱. **کانفیگ رایگان و سرویس اصلی، نقش جدا داشته باشند.** کنار خروجی عمومی یک footer کوتاه با مقصد خرید فعلی قرار بگیرد؛ پست مستقل، ویژگی‌های واقعی سرویس اصلی را توضیح دهد. نمونه مستقیم این مسیر در VPNsal، V2Shop و BlastPath دیده شد؛ اثر آن بر فروش آنان معلوم نیست.

۲. **شاهد مشخص از سرویس PV تولید شود.** گزارش شامل زمان، شبکه، دستگاه، لوکیشن/پلن و روش اندازه‌گیری خود PV باشد. «روی همه اینترنت‌ها بدون قطعی» از پژوهش رقبا قابل نتیجه‌گیری نیست. سلامت TCP کانفیگ عمومی نیز برابر با دسترسی موفق به اینستاگرام یا ثبات IP نیست.

۳. **CTA اصلی یک مقصد داشته باشد.** مقصد پیشنهادی موجود پروژه [@pvnetwork_bot](https://t.me/pvnetwork_bot) است. وجود منوی قیمت، تست، پشتیبانی و هر start parameter باید توسط اجرای اصلی به صورت خواندنی تایید شود. لینک جدید یا attribution ساختگی اختراع نشود.

۴. **گفت‌وگو بر اساس کاربرد باشد.** برای آیفون، راهنمای نصب؛ برای اینستاگرام، اتصال و آپلود؛ برای نیاز به کشور/IP مشخص، شرایط همان پلن بیان شود. صرف ثابت‌بودن IP، مجوز استفاده از همه پلتفرم‌ها یا تضمین حفظ حساب نیست. «آیپی ثابت» و «اختصاصی» دو ویژگی متفاوت‌اند و تنها روی پلنی که خود PV احراز کرده قابل ذکرند.

۵. **پایان تست، محرک واقعی داشته باشد.** پیام پایان تست فقط پس از `trial_expired` واقعی/زمان انقضای معتبر، برای لید مجاز، با cooldown و توقف روی خرید ارسال شود. اتمام حجم را با اتمام زمان اشتباه نگیریم. جایزه/تخفیف از رقبا کپی نشود؛ اقتصاد آن نیازمند سیاست واقعی PV است.

پیشنهاد آزمایش محدود: footer جدید در دو slot روزانه فعلی حفظ شود؛ مقایسه هفت‌روزه با baseline همان منبع و ثبت تعداد مشاهده‌شده ورودی قابل attribution، checkout، خریدار جدید و درآمد انجام شود. نرخ تبدیل فقط با صورت/مخرج هم‌گروه و حذف رویدادهای import/backfill گزارش شود. اگر main bot پارامتر کمپین را پشتیبانی نمی‌کند، محدودیت attribution صریح باقی بماند. افزایش کلی فروش هم‌زمان، به تنهایی اثر footer را اثبات نمی‌کند.

## مرز اجرا و فایل رجیستری

`config/competitor_sources.json` نمونه تحقیق دستی با لینک، تاریخ بررسی، شواهد خلاصه، CTA و محدودیت دسترسی است. تمام منابع `is_active=false` دارند؛ watcher روشن نشده، داده‌ای وارد production نشده و برنامه خزش ایجاد نشده است. `fields={}` عمدی است: regex ناپایدار برای قیمت/تست از HTML تلگرام ساخته نشده.

**این JSON مستقیم قابل import از API فعلی نیست.** مسیر `POST /admin/competitor-sources` فقط name/url/fields می‌پذیرد و مدل، `is_active=true` را پیش‌فرض می‌گیرد؛ واردکردن از آن مسیر شرط تحقیق دستی را نقض می‌کند. هیچ importer این فایل در این تغییر اضافه نشده است. برای پایش بعدی، ابتدا قرارداد غیرفعال‌بودن، parser دقیق، URL محدود و زمان‌بندی مجاز باید جداگانه بررسی شود.

تمام ادعاهای فروشندگان در رجیستری `performance_verified=false` هستند. تعداد عضو، بازدید و واکنش کانال شاخص درآمد یا رضایت تاییدشده نیست.
